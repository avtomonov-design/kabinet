# Кабинет витрины conтекст store

Веб-кабинет витрины: карточки «Девушкам» / «Парням», порядок перетаскиванием, цены и остатки 4Partners, фото из трафаретов Figma на GitHub, выгрузка в TgShop со сверкой.

Работает только вместе с расширением-мостом в Chrome: страница не хранит данных и не ходит в 4Partners/TgShop сама — это делает мост через входы пользователя. База и токены лежат в расширении на компьютере пользователя, в этом репозитории только код интерфейса.

Адрес: https://avtomonov-design.github.io/kabinet/
